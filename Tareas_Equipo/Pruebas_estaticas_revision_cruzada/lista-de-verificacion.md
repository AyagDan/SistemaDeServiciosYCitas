# Lista de verificación · ISO/IEC/IEEE 29148:2018

Cada revisor llena solo su bloque. En cada celda escribe **✓** si el requisito cumple o **✗** si falla. Cada ✗
se anota en la columna «Hallazgo» con una frase y, si se confirma en la reunión, se abre como issue.

Revisor: ____________________  Bloque: ____  Fecha: ____ / ____ / 2026  Versión revisada: v0.2.20

## Preguntas para el revisor

| Característica | Pregunta | Señal de falla |
| --- | --- | --- |
| Necesario (Nec) | ¿Sale de una entrevista, minuta o necesidad del cliente? | No tiene origen en la trazabilidad |
| Sin ambigüedad (Amb) | ¿Dos personas lo entenderían igual? | «rápido», «fácil», «adecuado», «etc.», «y/o» |
| Completo (Com) | ¿Dice qué pasa en los casos de error y en los límites? | Solo describe el camino feliz |
| Singular (Sin) | ¿Pide una sola cosa? | «registrar y calcular y notificar» |
| Factible (Fac) | ¿Se puede hacer con el tiempo, presupuesto y tecnología del equipo? | «en tiempo real», «por WhatsApp» sin costo analizado |
| Verificable (Ver) | ¿Se puede escribir un resultado esperado concreto? | No hay medida ni dato observable |
| Consistente (Con) | ¿Contradice a otro requisito o al glosario? | Un término distinto para lo mismo |
