\texttt{backend/app/servicios/ordenes.py}); cualquier transición que no aparezca aquí es rechazada por
el sistema y toda transición válida queda en HistorialEstado. Las historias de usuario (4.5), este modelo
y el código usan los mismos nombres de estado.
